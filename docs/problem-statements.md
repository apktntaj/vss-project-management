# PROBLEM STATEMENTS OF THE DOMAIN

A problem is a gap between the current state and the desired state. To create a better problem statement, we need to identify both states clearly. A problem statement emerges naturally when we recognize the gap between them.

## Current State

Vissasa handles events simultaneously using a chat that is shared across events in one place. This makes it difficult to maintain context. Since switching between events is challenging, it leads to confusion and inefficiency. Users often find themselves lost in the conversation, unable to track important information or decisions made during the work.

Vissasa also has a CRM-like application for events, but the current CRM feels unintuitive because it does not provide sufficient awareness of the events.

## Desired State

The desired state is to have a seamless event management system that allows users to handle multiple events simultaneously without losing context. Users should be able to switch between events easily, track important information, and make decisions efficiently. The system should provide a clear overview of all events, their statuses, and relevant details, enabling users to stay informed and organized.

## Problem Statement

The current event management system in Vissasa lacks the ability to handle multiple events effectively, leading to confusion and inefficiency. Users struggle to maintain context when switching between events, resulting in lost information and difficulty tracking important decisions.
